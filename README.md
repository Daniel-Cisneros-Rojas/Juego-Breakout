## Breakout Game
# Descripción
Este proyecto está inspirado en el clásico juego Breakout, donde el jugador controla una paleta para golpear una esfera y romper bloques en pantalla. Fue desarrollado en C# utilizando la biblioteca OpenTK, implementando algoritmos de colisión, animación y cálculos de rebote basados en ángulos de incidencia.

El objetivo principal es eliminar todos los bloques mediante el control preciso de la paleta y el aprovechamiento de la física de la esfera.

# Características
Desarrollo en C# con OpenTK.

Implementación de algoritmos de colisión entre esfera, paleta y bloques.

Cálculo de rebotes con ángulos de incidencia realistas.

Animaciones fluidas y dinámicas.

Estilo retro inspirado en el clásico Breakout.

# Tecnologías utilizadas
Lenguaje: C# 

Librería gráfica: OpenTK

Algoritmos: Colisión y rebote con ángulos
